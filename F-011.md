# DATABASE CHANGES

## 1. RENAME EXISTING TABLE
Rename `decision_documents` to `research_reports`.
This clarifies that the automated AI output is just a report, not the final decision.

## 2. NEW TABLE
`decision_records`

This is a thin wrapper holding user state, linked to the research report.

Columns:
id
workspace_id
research_session_id (Foreign Key to research_sessions)
title
status (PROPOSED, APPROVED, IMPLEMENTED, REJECTED, ARCHIVED)
created_by
created_at
updated_at

# MEMORY INTEGRATION

Decision Records become memory candidates.

---

Higher value than raw research.

---

Memory hierarchy:

Decision Memory

↓

Research Memory

---

**CRITICAL FIX**: 
Do NOT generate Pinecone memory automatically at the end of the LangGraph research.
Instead, memory generation is DEFERRED.
A memory is only generated and upserted when a user transitions a Decision Record to `APPROVED` or `IMPLEMENTED` status. This prevents cluttering the vector store with unverified AI research.
