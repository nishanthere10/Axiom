# FEATURE GOAL

Atlas generates valuable engineering decisions.

Users need to:

* Share them
* Archive them
* Attach them to PRDs
* Upload them to Notion
* Include them in RFCs
* Store them for future reference

Atlas must support professional exports.

This feature introduces:

* Markdown Export
* PDF Export
* ADR Export

using a shared structured export architecture.

---

# PRODUCT PRINCIPLE

Atlas does not export LLM text.

Atlas exports structured decision data.

Architecture:

Decision JSON

↓

Export Service

↓

Renderer

↓

File

---

# OBJECTIVE

Create a canonical export pipeline.

All export formats must originate from the same structured JSON source.

No format should have custom business logic.

Renderers only transform.
